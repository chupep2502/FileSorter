# FileSorter 1.1.0

Маленькое десктопное приложение для Windows: раскладывает файлы из любой выбранной
папки по подпапкам в зависимости от расширения **или даты**. Двуязычный интерфейс
RU/EN, светлая и тёмная темы (со следованием системной), все настройки правятся
прямо в окне. Один portable `.exe` — никаких установщиков и зависимостей.

## Что нового в 1.1.0

- **Drag & drop** — перетащите папку прямо в окно, чтобы выбрать её корнем.
- **Прогресс «X из Y»** — настоящая шкала прогресса вместо бесконечной.
- **Откат последней сортировки** — кнопка ⤺ возвращает все файлы из журнала
  на исходные места (журналы хранятся в `%APPDATA%\FileSorter\history\`).
- **Стратегии коллизий** — суффикс `(1)`, пропуск, перезаписать если новее,
  спросить (модалка с галочкой «применять ко всем»).
- **Сортировка по дате** — `2024`, `2024-03` или `Документы\2024` (по
  `LastWriteTime`). Включается на отдельной вкладке настроек.
- **Регулярные выражения по имени файла** — например, `^IMG_\d+` отправит
  `IMG_1234.bin` в «Изображения», даже если расширение не в списке.
- **Защита системных папок** — приложение откажется сортировать `C:\`,
  `C:\Windows`, `C:\Program Files`, `C:\Users\<you>` целиком и т.д.
- **Подтверждение для больших операций** — если файлов больше 500 или их объём
  больше 1 ГБ, появится диалог подтверждения.
- **Атомарное перемещение + проверка** — на одном томе используется атомарный
  `File.Move`; между томами — копирование с проверкой размера и времени, и
  только потом удаление оригинала.
- **Двойной клик по строке лога** — открывает Explorer с выделенным файлом.
- **Поиск по логу** — текстовое поле фильтрует строки на лету.
- **Лог в файл** — `%APPDATA%\FileSorter\logs\YYYY-MM-DD.log`, ротация 30 дней.
- **Подписанные `.exe`** — все 6 бинарей подписаны самозаверенным сертификатом
  (см. раздел **SmartScreen / подпись** ниже).
- **Иконка и метаданные** — у `.exe` теперь есть иконка и заполнены поля
  «Сведения» (версия, описание, копирайт).
- **xUnit-тесты** — `FileSorter.Tests/` (19 тестов, `dotnet test`).

## Готовые сборки (`dist/`)

Шесть вариантов — три архитектуры × два режима. Каждый вариант — **один `.exe`**,
портативный, можно копировать на любой Windows и запускать.

| Архитектура | Portable (self-contained) | Framework-dependent |
|---|---|---|
| **x64** (обычные ПК и ноутбуки) | `dist/win-x64-portable/FileSorter.exe` (~60 МБ) | `dist/win-x64-framework/FileSorter.exe` (~0.27 МБ) |
| **x86** (старые 32-битные системы) | `dist/win-x86-portable/FileSorter.exe` (~55 МБ) | `dist/win-x86-framework/FileSorter.exe` (~0.24 МБ) |
| **ARM64** (Snapdragon, Surface Pro X, Apple Silicon под Parallels) | `dist/win-arm64-portable/FileSorter.exe` (~57 МБ) | `dist/win-arm64-framework/FileSorter.exe` (~0.26 МБ) |

### Какой вариант выбрать?

- **Portable** — самодостаточный. Внутри лежит вся .NET 9 runtime. Скопировал на
  флешку → запустил на чужом ПК → работает. Большой размер — плата за переносимость.
- **Framework-dependent** — компактный, но требует установленный
  **.NET 9 Desktop Runtime** на целевой машине. Скачать:
  <https://dotnet.microsoft.com/download/dotnet/9.0> → раздел *Desktop Runtime*.
  Подходит, если вы уже знаете, что .NET 9 на машине есть.

> Почему не получилось ужать portable до 5–10 МБ? WPF официально несовместим с
> trimming (`PublishTrimmed=true` → ошибка `NETSDK1168`): XAML-парсер использует
> рефлексию, и trimmer срезает слишком много. ~60 МБ для self-contained WPF —
> практический минимум при включённой компрессии.

### SmartScreen / подпись

Все 6 `.exe` подписаны самозаверенным (self-signed) сертификатом
**`CN=FileSorter Self-Signed (chupep)`**, его открытая часть — рядом с релизом
в файле `FileSorter.cer`. Подпись помечена временной меткой DigiCert, поэтому
останется валидной даже после истечения срока сертификата.

Для Windows этот сертификат всё равно «неизвестный издатель», и SmartScreen при
первом запуске покажет «Защитник Windows предотвратил запуск неопознанного
приложения» → **Подробнее → Выполнить в любом случае**. Это разовое действие на
каждый компьютер.

Если хотите убрать предупреждение совсем — установите `FileSorter.cer` в
**Доверенные корневые центры сертификации** (Trusted Root Certification
Authorities) на целевой машине. После этого SmartScreen перестанет ругаться на
все будущие сборки, подписанные тем же сертификатом.

## Использование

### Главное окно

1. **Папка** — выпадающий список с историей последних папок. Можно выбрать через
   «Обзор...», вставить путь руками или **перетащить папку** прямо в окно.
2. **Включая вложенные папки** — рекурсивно обойти подпапки. По умолчанию
   выключено, чтобы не трогать уже разложенные файлы внутри созданных категорий.
3. **Только предпросмотр (dry-run)** — показать в логе, что было бы перемещено,
   но реально не двигать файлы. Эквивалент кнопке **Предпросмотр**.
4. **Сортировать** — выполнить перемещение. Появится прогресс «X из Y».
5. **Отмена** — прервать долгую сортировку.
6. **Откат** (⤺) — вернуть файлы из последней сортировки на исходные места.

Двойной клик по строке лога открывает Explorer и выделяет файл.

### Переключатели в шапке

- **Тема** — Системная / Светлая / Тёмная.
  - *Системная* следует за Windows: переключите в Параметрах → Персонализация →
    Цвета → светлая/тёмная — приложение подхватит за пару секунд.
  - Светлая и Тёмная — фиксированные, игнорируют системную.
- **Язык** — Русский / English. Меняется на лету.

### Окно настроек (⚙)

Четыре вкладки:

- **Категории** — таблица с ID, русским и английским именем папки, списком
  расширений (через запятую) и списком регулярных выражений по имени
  (через `;`). Регулярки применяются, если расширение не нашлось в списке —
  удобно для масок типа `^IMG_\d+` или `^[А-Я][а-я]+_2024`. Строки можно
  добавлять/удалять. ID нужен, чтобы при смене языка приложение знало,
  какую существующую папку считать «той же самой» — поэтому ID лучше не менять.
  Сохранение валидирует все ID и регулярки и не закрывает окно при ошибке.
- **Исключения** — расширения, которые **не трогать**. По умолчанию `.lnk`,
  `.url`, `.ini`.
- **Поведение** — дефолты галочек главного окна, имя папки «Прочее» для
  файлов с неизвестными расширениями (можно отключить целиком), и
  **стратегия коллизий**: суффикс / пропустить / заменить если новее / спросить.
- **Дата** — режим сортировки: по расширению (по умолчанию), по году,
  по году-месяцу или по расширению + году. Дата берётся из `LastWriteTime`
  файла.

## Стандартные категории

| ID | Имя (RU) | Имя (EN) | Расширения |
|---|---|---|---|
| documents | Документы | Documents | .pdf, .doc(x), .xls(x), .ppt(x), .txt, .rtf, .odt, .ods, .odp, .csv, .md, .epub, .mobi, .djvu |
| images | Изображения | Images | .jpg, .jpeg, .png, .gif, .bmp, .tif(f), .webp, .svg, .ico, .heic, .raw, .psd |
| videos | Видео | Videos | .mp4, .mkv, .avi, .mov, .wmv, .flv, .webm, .m4v, .mpg, .mpeg, .3gp |
| audio | Аудио | Audio | .mp3, .wav, .flac, .aac, .ogg, .wma, .m4a, .opus, .aiff |
| archives | Архивы | Archives | .zip, .rar, .7z, .tar, .gz, .bz2, .xz, .iso, .cab |
| installers | Установщики | Installers | .msi, .msix, .appx, .appxbundle |
| programs | Программы | Programs | .exe |
| code | Код | Code | .py, .js, .ts(x), .jsx, .html, .css, .json, .xml, .yaml, .sh, .ps1, .bat, .cmd, .c, .cpp, .h(pp), .cs, .java, .go, .rs, .rb, .php, .sql, .ipynb |

### Миграция существующих настроек

При запуске новой версии поверх старого `settings.json`:

- категория `images` («Фото») автоматически переименовывается в «Изображения»
  (если имя не было изменено вручную);
- из `installers` автоматически выносится `.exe` в новую категорию `programs`,
  если её ещё нет;
- новые поля (`NameRegex`, `CollisionStrategy`, `SortMode`) подхватывают
  значения по умолчанию (пустой список / `Suffix` / `ByExtension`).

Ручные правки имён и расширений не затрагиваются.

## Где что лежит

| Путь | Что |
|---|---|
| `%APPDATA%\FileSorter\settings.json` | Все настройки. Удалите файл — будут восстановлены дефолты. |
| `%APPDATA%\FileSorter\history\*.json` | Журналы перемещений (для отката). Хранятся последние 10. |
| `%APPDATA%\FileSorter\logs\YYYY-MM-DD.log` | Текстовый лог. Ротация 30 дней. |

Все три каталога — на уровне пользователя, переносятся обычным копированием.

## Сборка из исходников

Требования: **.NET SDK 9.0+** (`dotnet --list-sdks` должен показать `9.x`).

```powershell
cd C:\Users\chupep\FileSorter
dotnet build -c Release
dotnet run -c Release
```

### Тесты

```powershell
dotnet test FileSorter.Tests\FileSorter.Tests.csproj
```

19 xUnit-тестов покрывают ядро `SorterService`: dry-run, реальное перемещение,
все стратегии коллизий, папка «Прочее», регулярки, режимы дат, прогресс-каунтер,
валидация корневой папки, рекурсия без повторной сортировки, журнал отката.

### Все шесть бинарей сразу

```powershell
foreach ($rid in @('win-x64','win-x86','win-arm64')) {
    # Portable, self-contained, single-file, compressed
    dotnet publish -c Release -r $rid --self-contained true `
        /p:PublishSingleFile=true `
        /p:IncludeNativeLibrariesForSelfExtract=true `
        /p:EnableCompressionInSingleFile=true `
        -o "dist/$rid-portable"

    # Framework-dependent, single-file
    dotnet publish -c Release -r $rid --self-contained false `
        /p:PublishSingleFile=true `
        -o "dist/$rid-framework"
}
```

### Подпись бинарей

Скрипт `Tools\sign-build.ps1` создаёт (или переиспользует) самозаверенный
сертификат в `Cert:\CurrentUser\My`, экспортирует открытую часть в
`FileSorter.cer` и подписывает указанные `.exe` через `signtool.exe` из
Windows SDK с временной меткой DigiCert:

```powershell
$exes = Get-ChildItem dist -Recurse -Filter FileSorter.exe | % FullName
.\Tools\sign-build.ps1 -Targets $exes
```

Для запуска нужен установленный **Windows 10/11 SDK** (раздел *Signing tools*).

### Иконка

Если хотите перегенерировать иконку приложения:

```powershell
.\Tools\make-icon.ps1 -OutputPath .\Resources\app.ico
```

## Безопасность

- Перемещение происходит только **внутри** выбранной корневой папки. Целевой
  путь обязан начинаться с пути источника — иначе файл пропускается.
- Файлы, уже лежащие в папке-категории (при рекурсивном обходе), не трогаются —
  никаких бесконечных вложений «Документы/Документы/...».
- Сам исполняемый файл приложения никогда не двигается.
- Корневые системные пути (`C:\`, `C:\Windows`, `C:\Program Files`,
  `C:\Users\<you>`) запрещены — приложение откажется их сортировать.
- Большие операции (>500 файлов или >1 ГБ) требуют отдельного подтверждения.
- При совпадении имён в целевой папке поведение определяется **стратегией
  коллизий**: суффикс `(1)`, пропуск, перезапись если источник новее, или
  ручной выбор в диалоге.
- Между разными томами файл **сначала копируется и проверяется** (размер +
  `LastWriteTime`), и только затем оригинал удаляется. При сбое проверки
  частичная копия удаляется, оригинал остаётся.
- Каждая сортировка пишет журнал в `%APPDATA%\FileSorter\history\` —
  кнопка **Откат** возвращает файлы на места.

## Что не входит в приложение

- Кроссплатформенность — только Windows (WPF).
- Hash-based проверка содержимого при перемещении (только размер + время).
- Cloud-провайдеры (OneDrive offline placeholders и т.п.) — обрабатываются
  как обычные файлы; если файл не скачан, ОС подгрузит его при копировании.
